# Mascot rig specification

Status: **Gate 1 proposal, v0.1.1** (Cram fork hand, Nest dome and Lull crescent corrected after the first silhouette pass). Machine version: `system/rig-spec.json`. Exact required ids per mascot: `system/rig-manifest.json` (generated by `tools/check-rig.py`). Every rig SVG in `static/` is checked automatically against this spec.

**Purpose.** Claude Design draws each mascot once, as layered and named SVG. Claude Code animates those named layers by transforming and swapping them, and never redraws (brief Section 24). Anything that would need a redraw goes back to Design. This spec makes sure every pose, expression and motion clip in Gates 2–4 can be built from the same drawing.

---

## 1. Canvas

| Property | Value |
|---|---|
| viewBox | `0 0 1024 1024` (1 rig unit = 1 SVG user unit) |
| Ground line | y = 896. Feet, base or foot-ring rest exactly on it. |
| Centre line | x = 512. The mascot's centre of mass sits on it in the front view. |
| Safe box | x 128–896, y 128–896 (768 × 768). Nothing in body, face, limbs or props may leave it. |
| Height | `persona.mascot.heightRatio × 768` (see table in section 7) |
| Tolerance | ±8% on every construction number without approval |
| Coordinates | rounded to 0.5 rig units |

## 2. Files and views

`static/{slug}/{NN}-{mascot}-rig-{view}.svg`, one SVG per view.

- Views: `front`, `three-quarter`, `side`. Three-quarter and side face screen-right.
- **All views of a mascot use exactly the same ids.** One animation file then drives any view.
- Example: `static/01-hostel-hungry/01-cram-rig-front.svg`.

## 3. Id grammar

```
{mascot}__{slot}[__{part}[__{subpart}]][--{state}]
```

| Piece | Rule | Examples |
|---|---|---|
| `mascot` | one of `cram riot nest sprig lull stack mise` | `riot` |
| `slot` | one of the ten slots in section 4 | `face` |
| `part`, `subpart` | lowercase kebab words; left and right are the mascot's own, written `-l` and `-r` | `lid-l`, `flame-hair`, `flame-2` |
| `state` | lowercase kebab word after `--`; alternate drawings of the same part | `--half`, `--smile` |
| separators | `__` between hierarchy levels, `-` inside a name, `--` before a state | `lull__face__lid-l--half` |

Regex (from `rig-spec.json`):
`^(cram|riot|nest|sprig|lull|stack|mise)__(background|environment|limbs-back|body|face|limbs|props|noodles-steam|foreground-type|rig)(__[a-z0-9]+(-[a-z0-9]+)*){0,2}(--[a-z0-9]+(-[a-z0-9]+)*)?$`

Every `<g>` and every animated `<path>` carries an id. Unanimated decoration may be anonymous, but only inside a named group.

## 4. Slots: document order is layer order

The top-level `<g>` elements are direct children of `<svg>`, in exactly this order (back to front). This matches `motion.layer-order` in `tokens.json` (brief Section 20), plus two rig-only slots.

| # | Slot id | Contents | Required |
|---|---|---|---|
| 1 | `{m}__background` | flat backdrop for the sheet (usually empty in rig files) | yes |
| 2 | `{m}__environment` | ground shadow, table edge, scene props that never move with the mascot | yes |
| 3 | `{m}__limbs-back` | far-side arm and leg in three-quarter and side views | optional (Gate 1 decision D6) |
| 4 | `{m}__body` | torso, worn items, persona body parts, `__detail` | yes |
| 5 | `{m}__face` | eyes, lids, brows, mouth, persona face parts | yes |
| 6 | `{m}__limbs` | near-side arms and hands, legs and feet if any | yes |
| 7 | `{m}__props` | sachet (required), signature props, held items | yes |
| 8 | `{m}__noodles-steam` | noodles, 3 steam wisps, persona steam parts | yes |
| 9 | `{m}__foreground-type` | the persona "2" mark, labels, optional empty lockup-slot rectangle | yes |
| 10 | `{m}__rig` | hidden anchor markers (`display="none"`) | yes |

## 6. Anchors

Anchors are zero-size circles inside `{m}__rig`: `<circle id="{m}__rig__{anchor}" cx="…" cy="…" r="0"/>`. Code reads `cx`/`cy` as the transform-origin of the part each anchor drives.

| Anchor | Drives | Placement |
|---|---|---|
| `root` | whole mascot: bounce, squash and stretch | **fixed at (512, 896)** in every view |
| `body-pivot` | body | centre of mass of `body__torso` |
| `head-pivot` | face and head-mounted props | base of the head (rim centre for vessel mascots) |
| `eye-l`, `eye-r` | lid `scaleY` for blinks | centre of each eye |
| `mouth` | mouth state swaps | centre of `face__mouth--neutral` |
| `shoulder-l`, `shoulder-r` | arm rotation | arm root on the torso |
| `wrist-l`, `wrist-r` | hand rotation | arm end |
| `grip-l`, `grip-r` | held props (the sachet defaults to `grip-r`; Cram's fork is in `grip-l`) | palm centre |
| `steam-origin` | noodles-steam group | centre of the vessel rim |
| `sachet-tear` | `props__sachet__tear-strip` | inner tip of the notch |
| `look-at` | pupil offset target | default gaze point, 400 units in front of the face |

## 8. Level of detail

- Any group whose id ends in `__detail` is hidden in renders at or below 64px.
- Recognition features (the silhouette hook, eyes, the sachet outline) must **never** sit in a `__detail` group, and must be drawn with strokes or features ≥ 16 rig units (1px at a 64px render).
- The 32px silhouette test renders every slot except background, environment, foreground-type, rig and `__detail` groups, filled `#000000`.

## 10. SVG rules

1. Static SVG only: no `<script>`, `<foreignObject>`, `<image>` or external references.
2. No `<text>`: lettering is outlined paths. The one exception is the empty `{m}__foreground-type__lockup-slot` rectangle.
3. Groups carry `translate()` only. No rotate, scale, skew or matrix baked into animatable groups; geometry sits in its final position.
4. Strokes stay strokes, with the width from `persona.*.shape.stroke`. Don't expand outlines on animatable parts.
5. Colours are exact hex values from `system/tokens/personas/NN-mascot.tokens.json`. Nothing else.
6. No `clip-path` or `mask` on animatable groups unless the mask itself has an id in the same slot.
7. One `<svg>` per view.

## 11. How Code animates (for reference)

| Motion | Parts and anchor | Token |
|---|---|---|
| Breathing idle | `body` scaleY around `body-pivot`, amplitude × persona `amplitude` | `ease-settle`, idle 2 s or 4 s |
| Blink | `lid-*` swap `open → half → closed → open` over 4 frames | n/a |
| Pop / reaction | `root` squash and stretch up to `squashStretch`, anticipation of `anticipationFrames` | `ease-in-soft` then `ease-out-pop` |
| Steam | `steam-1…3` translateY + opacity from `steam-origin`, staggered by `staggerFrames` | `ease-linear-steam` |
| Sachet tear | `sachet__tear-strip` rotate around `sachet-tear` | `ease-out-pop` (Riot, Cram), `ease-settle` (others) |
| Secondary overlap | hair, leaves, noodles delayed by `staggerFrames` | `ease-settle` |
