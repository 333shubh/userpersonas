# ChatGPT prompts: the seven eating scenes (task output)

Version 1.0, 2026-10-07. This covers the task's "illustration of each persona eating Maggi". Each scene uses its persona file's section 10: same hour, light, set, props and density. The one change is that the mascot is **eating** in every scene, because the task asks for it. Mascots follow the approved heroes (`static/NN-slug/NN-mascot-hero.png`) and `system/mascot-style-v3.md`.

## How to make them

1. Open the ChatGPT chat where the mascot's hero was made, or start a new chat and attach the approved `NN-mascot-hero.png` (the version without the pack).
2. Paste the mascot's prompt below. **Landscape 3:2.**
3. Save the image as `static/NN-slug/NN-mascot-scene.png` (for example `static/02-maximalist-foodie/02-riot-scene.png`).
4. If the character drifts from the hero (head, colours, outfit, 4 fingers), reply: `The character changed: [part]. Keep the scene and redraw the character exactly like the attached hero.`
5. Packs and cups in the scene are **plain** on purpose. Claude Code composites the real MAGGI pack on afterwards, as for the heroes.

Every prompt ends with the same avoid list: no display base, no readable text except where stated, no logos, no watermark, no realistic human face, no child face or figure, no cultural costume, 4 fingers per hand.
