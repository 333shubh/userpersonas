# Fonts for the Claude Design generators

`tools-design/gate2-build.js` outlines lettering from these TrueType files. They are **not committed**:
they are third-party fonts under the SIL Open Font License, and redistributing them requires shipping
each family's licence text. Download them from Google Fonts into this folder before rebuilding:

| File | Family (Google Fonts) |
|---|---|
| `ArchivoBlack-Regular.ttf` | Archivo Black |
| `IBMPlexMono-Regular.ttf`, `IBMPlexMono-SemiBold.ttf` | IBM Plex Mono |
| `Bungee-Regular.ttf` | Bungee |
| `Rubik-wght-.ttf` | Rubik (variable weight) |

The committed SVGs already contain the lettering as outlined paths, so nothing else needs these files.
